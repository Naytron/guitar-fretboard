About this demo

This is a small, original demo that turns a scale diagram (the kind on a printed “G Major Scale — Fretboard” sheet) into an interactive web page. It defaults to G major — G A B C D E F♯ — and works for any root, mode, or basic chord.

The note names are calculated from the open-string tuning by simple chromatic math (note = (open + fret) mod 12) and spelled with sharps or flats to match the selected key. Nothing here is reproduced from copyrighted sheet music.

Built as an interactive companion to my personal guitar library. All code & note data original.
